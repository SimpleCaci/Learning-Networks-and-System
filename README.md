# Learning Networks and Systems

A practical study repository for Linux, networking fundamentals, reconnaissance concepts, and small defensive learning scripts.

## Tech stack

- Python
- Linux command-line tools
- TCP/IP and port concepts
- Markdown lab notes
- Virtual-machine practice environments

## Contents

- `Notes/` — Linux, networking, and reconnaissance notes.
- `Projects/` — VM setup and guided lab walkthroughs.
- `Scripts/` — a password-strength checker and simple port scanner.

## Setup

```bash
python setup.py
```

Individual scripts can also be run directly with Python. Use the networking exercises only against systems you own or have explicit permission to test.

## Status

Educational lab notebook. The goal is to show progressive systems understanding, not to package the scripts as production security tools.
